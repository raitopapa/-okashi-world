# 仕様対応と検証記録

更新日：2026-09-10。v2は提供された絵本を参考に、材料作りから家づくりまでの世界観を改修しています。

## 対応状況

| 仕様 | 実装 |

| 自由な家づくり | 24種類のお菓子、6カテゴリ。配置・移動・重ね置き・片付け・取り消し。初期のおうちを飾る／空の工事場から作る。 |
| 絵本を踏まえた世界観 | 明るい果樹の工事場、細い茶色の輪郭、ビスケットのれんが、食べ物としてわかる屋根・窓・ドア。うさぎ・ビーバー・ハリネズミの職人。 |
| 作る・運ぶ・建てる | 配置時の手押し車での材料運び、職人の応援、完成時の喜ぶ演出。動きを減らす設定に対応。 |
| れんが作り | 生地をタップしてクッキーを作る。約30秒で壁を2種類解放。 |
| チョコ混ぜ | 指でなぞるとチョコの渦が動く。約30秒で屋根を2種類解放。 |
| 材料集め | 材料をカゴへドラッグ／材料→カゴの順にタップ。約35秒で飾りを2種類解放。落ちた材料は再登場。 |
| かまど焼き | 生地を入れて約30秒待つ演出。土台を2種類解放。ドラッグと2回のタップを利用可能。 |
| 保存・再編集 | IndexedDBの編集中自動保存と、サムネイル付きアルバム。アプリ側の件数上限なし。既存16パーツのID・寸法・重なり順を維持。 |
| 誤操作への配慮 | 取り消し、減点なし、新規作成・別作品切替前の保存。保存失敗時は元の作品を維持。 |
| 音設定 | BGM・効果音・端末内の日本語音声を切替。計算で保護者設定を開く。 |
| オフライン | 全実行ファイル・素材を事前キャッシュ。キャッシュのバージョンはv2.0.0。ルート配信とGitHub Pagesのサブディレクトリ配信を考慮。 |
| 課金・広告・外部共有なし | 該当機能や解析通信を実装していない。クラウドDBなし。 |

## 実行済みの確認

`node scripts/check.mjs`：JavaScript構文、ローカル参照、PWAマニフェスト、必須素材の存在を確認。Webアプリ一式16ファイル、約4.18MiB。

`node --test tests/*.test.mjs`：13テスト成功。

- 32点すべての切り出しが実画像の寸法内にあり、部材・職人・道具の参照先が揃う。
- v1の全16種類を含む保存レコードでID・寸法・重なり順を維持し、読み取りが配置を書き換えない。
- 各ミニゲームは1〜2種類を解放し、4種類を遊ぶと全24パーツが使用可能になる。繰り返しても進行を失わない。
- 独立したID、画面内への配置制限、手前の部材の選択、取り消し、不正なレコードの排除。
- 全配信素材を事前キャッシュし、模擬オフライン環境でHTMLと画像を取得する。
- 新規素材と座標定義を、GitHub Pages形式のサブディレクトリからオフライン取得する。隣のサイトは横取りしない。
- 他アプリのキャッシュを残し、途中で失敗した初回ダウンロードを有効化しない。他ドメインとPOSTは横取りしない。

以上はNode.js上のモデル・Service Worker制御のテストと静的検証です。ブラウザによるE2Eテスト、iPad/Safari実機、実際のIndexedDB、ホーム画面への追加、機内モードでの再起動、実音声再生は未確認です。

## 制約

- 声かけは端末内の日本語音声が使える場合のみ。ネットワーク音声には切り替えない。
- 保存は端末・ブラウザ・配信URLごと。端末間同期やバックアップ書き出しは対象外。
- 容量不足・サイトデータ削除などでキャッシュや作品データが失われる可能性がある。
- 新しいURLへ配信しても、旧URLの作品は自動で移動しない。
- ゲームのアカウント登録はない。非公開ホスティングの認証がある場合は、配信サービス側の認証が最初に必要になる。
- iPad実機で操作とオフライン起動が通るまでは、実機動作確認済みとは扱わない。
