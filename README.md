# おかしのおうち 🍪

3〜5歳向けの、お菓子の家づくりPWAです。動物の職人たちと材料を作り、運び、24種類のお菓子で自由に家を建てます。

v2では、果樹に囲まれた工事場、ビスケットのれんが、ワッフルやプリンの屋根、板チョコのドア、ドーナツとプレッツェルの窓を追加。材料カタログ、動物の作業員、れんが作り・チョコ混ぜ・材料運び・かまど焼きの絵を統一しました。

v2.1では、森・海辺・雪の広場を選べるようにしました。声かけは完成時のみ、20種類を使い分け、最低25秒間隔。お菓子作りは操作で完成し、かまども約2秒（タップですぐ取り出し）になりました。

v2.2では背景とBGMを連動。森は軽やかな旋律、海辺はゆっくりした柔らかな音、雪の広場は間を取ったベル調です。切替時は前の曲がフェードアウトし、保存した作品を開くとその背景の曲に戻ります。端末内で合成するためオフラインでも利用できます。

## 起動

Node.js 20以降を用意し、このフォルダで実行します。依存パッケージのインストールやビルドは不要です。

```bash
npm start
```

PCのブラウザで `http://localhost:8080` を開いてください。終了は Ctrl+C。

```bash
npm run check
npm test
```

`dist/` が配信するWebアプリ一式です。HTTPSに対応した静的ホスティングへ、そのまま配置できます。サブディレクトリでの配信を考慮し、参照先を相対パスにしています。

## iPadであそぶ

1. 配信されたHTTPSのURLをSafariで開きます。端末のファイルアプリからHTMLを直接開く方法ではオフライン機能は動作しません。
2. 右上の歯車 → 保護者向けの計算 →「オフラインの準備ができました」を確認します。
3. Safariの共有メニューから「ホーム画面に追加」。追加したアイコンを通信できる状態で一度開き、そこでオフライン準備の完了を確認します。
4. 以後は同じアイコンから起動します。端末を機内モードにして、再起動できることを確認してください。

音は最初のタップで有効になります。BGM・効果音は端末内で合成します。日本語の声かけは、端末内で利用できる日本語音声がある場合に限ります。

PCの `localhost` はService Workerを利用できます。iPadからPCのLANアドレスへ平文HTTPでアクセスする場合は、オフライン動作を検証できません。iPadでの確認にはHTTPSの配信先を使ってください。

## あそびかた

- **こうじば**：下のカテゴリからパーツを選び、庭にドラッグ。パーツをタップしてから、置きたい場所をタップしても配置できます。
- **ばしょ**：カタログ上の「ばしょ」から森・海辺・雪の広場を選べます。家の配置を維持し、背景も作品と一緒に保存します。
- **動かす**：置いたパーツをドラッグ。重ねて配置できます。壁 → 屋根 → 窓・ドア → 飾りの順に表示します。同じ種類の重なりは、動かしたパーツが手前になります。
- **しまう・もどす**：選んだパーツを箱のボタンで片付けます。戻すボタンで配置・移動・片付けを取り消せます。
- **おしごと**：クッキーのれんが作り、チョコ混ぜ、材料集め、かまど焼きの4種類。れんがは4回、材料は3個、チョコは6タップまたは混ぜる操作で完成。かまどは約2秒、焼いている途中のタップですぐ取り出せます。完成するとそれぞれ1〜2種類のパーツが使えるようになります。
- **できあがり**：カメラのボタンでアルバムへ保存。同じおうちの保存は更新になります。
- **あたらしく**：今のおうちをアルバムに保存して、空の庭から始めます。保存に失敗したときは元のおうちを残します。
- **アルバム**：サムネイルをタップして続きを編集できます。
- **保護者設定**：右上の歯車から音楽・効果音・声かけを切り替えます。

動物をタップすると案内を表示します。音声の声かけは家やお菓子の完成時だけで、最低25秒間隔、各場面4種類を順番に使います。材料を置くとハリネズミが手押し車で運び、完成時には仲間が喜びます。動きを減らす端末設定では、配置時の移動・跳ねる演出を止めます。

パーツの使用回数には制限がありません。ミニゲームで落ちた材料はまた現れ、減点や失敗はありません。解放済みのミニゲームも繰り返し遊べます。キャッチとオーブンは「選ぶ → 入れ先をタップ」でも操作できます。

## 保存の仕様

IndexedDBに編集中の作品、解放済みパーツ、音設定、アルバムを保存します。配置・移動・取り消しごとに編集中の内容を自動保存します。アルバムの保存件数にアプリ側の上限はありません。アカウント、サーバー保存、広告、課金、解析通信、SNS共有はありません。

保存先は端末・ブラウザ・配信URLごとに分かれます。別の端末や別URLへ作品は自動転送されません。ブラウザのサイトデータ削除やOSによる保存領域の整理で消える場合があります。空き容量不足などは保護者向けに表示し、保存できたと偽って扱いません。取り消し履歴は起動中のみ最大60操作です。

以前の16種類のパーツID・大きさ・重なり順とIndexedDBの保存形式を維持しています。保存済み作品の配置や解放状態を引き継ぎ、古いアルバムのサムネイルは新しい絵で表示します。

## 構成と実装方針

```text
dist/
  index.html             家づくり・ミニゲーム・アルバム・設定
  style.css              iPad縦横・スマホ対応
  manifest.webmanifest   ホーム画面アイコン・PWA定義
  sw.js                  全素材のオフラインキャッシュ
  assets/                工事場の背景・24種のお菓子・8種の職人／道具・アイコン
  js/
    app.js               操作・画面切替・保存連携
    model.js             パーツ定義・座標・解放・履歴
    art.js               スプライト・職人・画面描画・サムネイル
    atlas-map.js         32点の素材の実測切り出し座標
    minigames.js         4種類のミニゲーム
    storage.js           IndexedDB
    audio.js             Web Audio・端末内の日本語音声
scripts/
  serve.mjs              ローカル配信
  check.mjs              構文・素材参照検証
tests/                   ゲームモデル・オフライン制御のテスト
docs/
  VERIFICATION.md        対応状況・検証範囲・実機確認項目
LICENSES.md              素材の制作区分
```

HTML/CSS/ES Modules + Canvas 2Dで実装しています。外部ライブラリやCDNを使わず、初回配信を軽くしています。Canvasは端末解像度に合わせ、アイドル時の家づくり画面は連続描画を止めます。ミニゲームとBGMはバックグラウンドで進まないようにしています。

画面遷移は「こうじば ⇔ おしごと／アルバム」。ミニゲームは「おしごと → ゲーム → 材料完成 → こうじばへ運ぶ」。設定は保護者用ダイアログです。

実装順序：家づくりと素材 → ミニゲームと保存 → PWA対応・検証・手順書。開発後はiPad実機の操作感を確認して調整します。

更新時は `dist/sw.js` の `VERSION` を変更します。新しい素材が増えたら `FILES` に加え、`npm run check` と `npm test` を実行してください。初回のキャッシュが途中で失敗した場合はオフライン準備完了にはしません。

検証済みの範囲と実機未確認事項は [docs/VERIFICATION.md](docs/VERIFICATION.md)、素材情報は [LICENSES.md](LICENSES.md) を参照してください。
